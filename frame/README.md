# Accnary

Windows 本地账号与密码管理器，Python + PySide6 Widgets + PyKeePass，标准 KDBX 4。
按需打开、输入主密码、搜索与复制，用完关闭即退出；不使用托盘或全局热键，不含浏览器监测、自动填充、云端或开机启动。

首发版本为 **0.1.0**。当前源码提供 ToolHub 更新检查；启动时可自动检查（默认开启），也可从“更多 → 检查更新”手动检查。检查只读取 ToolHub 清单；下载和安装需要用户确认，绝不自动替换程序。

## 使用与开发

```powershell
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -B -m pytest tests -p no:cacheprovider
```

依赖继续以 `requirements-lock.txt` 为准，原有 `.venv` 使用本机 Python，没有新安装解释器。
根级测试 fixture 自动隔离 INI 设置，所有测试库均为虚构凭据。
`ACCNARY_SETTINGS_DIR` 是进程级测试偏好目录覆盖；普通启动继续使用既定 APPDATA 路径。

## 主要行为

- QQ、微信、邮箱、网站、软件及科研平台都是普通账户记录；同平台可保存多个账号。
- 账号用途分类按用户明确选择保存；QQ、微信属于普通社交账号记录，支持多个记录放在同一分类。
- 登录方式、身份绑定、不同用途的邮箱及软件许可证分别保留；身份通过 UUID 引用。
- 搜索支持名称、邮箱、手机号、域名、网址片段以及粘贴的长网址；不联网访问网址。
- 更新功能只通过 HTTPS 访问 ToolHub 清单；更新安装前需确认并校验 SHA-256，不上传密码库、凭据或使用数据。
- 密码和受保护字段默认隐藏；复制使用单一计时器，到期、锁定和退出时条件清理。
- 收藏界面已移除，旧库收藏标记保留兼容；最近使用继续自动记录。
- 保留手动锁定、空闲锁定及 Windows 会话锁定/休眠消息联动；锁定后在主窗口输入主密码，继续打开当前库。
- 关闭时保存待提交的模型改动；失败可取消退出。取消编辑不会提前写入身份。
- 安全保存使用跨进程写入锁、同目录加密暂存、重开内容验证、快照和替换。
- 侧栏“备份与恢复”接通已有加密导出与恢复服务；恢复需确认，旧备份使用旧主密码。
