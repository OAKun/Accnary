## 1. 交付内容

### 1.1 全局智能搜索（app/services/search_service.py，spec 第 5 节）

- **纯内存索引**：解锁后构建（load/save 时自动重建），锁定即清除 ——
  绝不落盘（自动化测试断言 lock 后索引为 0）。
- **敏感值绝不进索引**：密码、许可证激活码、自定义字段"值"（可能存放
  API Token/恢复码）全部排除，测试逐一断言搜索这些值无结果；自定义
  字段"键"可搜。
- **四级评分**：精确 > 前缀 > 包含 > 子序列容错（ethdta → earthdata）；
  多词查询 AND 语义；容错结果设最低分阈值防噪。
- **专项优化**：域名查询加权（pan.baidu.com / urs.earthdata.nasa.gov
  直接命中平台）；手机号去 +86/分隔符归一化（13800000000 命中
  +86-138-0000-0000）；邮箱拆本地/域名；微信/QQ 身份的名称与值可反查
  绑定账户；订单号/渠道/标签/分类/平台类型中英全可搜；大小写无关。
- **性能**：2000 账户全库重建 + 单次查询远低于 200ms 预算（测试断言）。
- 主窗口集成：搜索框输入即切换为评分结果（副行显示"匹配：域名"等
  命中提示），状态栏显示"N 个结果"；清空恢复分类浏览。

### 1.2 日常体验

- **复制即记录**：详情面板任何"复制"（用户名/密码/网址/激活码/字段）
  自动 touch_last_used 并立即持久化（失败不影响复制本身）；"最近使用"
  分类随之生效。
- **密码生成器策略面板**：长度 8-128、四类字符开关、排除易混淆字符、
  自定义排除字符表、实时预览、一键采用。
- **平台属性编辑**：编辑对话框"更多选项"新增平台信息组（分类/标签/
  平台别名/平台网址/类型），保存时同步重写该平台所有账户的 Meta 服务块
  （测试验证每个条目都更新）。
- **回收站对话框**：工具栏入口，列出回收站中的 Accnary 条目，一键恢复
  到原平台（非 Accnary 条目不显示也不触碰）。

### 1.3 Windows 集成（spec 第 8 节）

- **系统托盘**：关闭窗口 = 最小化到托盘（带气泡提示），托盘菜单
  显示/隐藏、锁定、退出；真正的退出只能从托盘发起。
- **空闲自动锁定**：应用事件级活动监测（键盘/鼠标/滚轮），默认 10 分钟
  无操作自动锁定；设置菜单可切 5/10/15/30 分钟或禁用，偏好持久化。
- **Windows 会话锁定联动**：WTSRegisterSessionNotification 监听
  Win+L 锁屏，立即锁定密码库（平台不可用时静默降级）。
- **全局呼出热键**：Ctrl+Alt+A 显示/隐藏主窗口（RegisterHotKey，
  用户级 API 不改系统配置；设置菜单可停用）。以上三者均为可降级设计，
  offscreen/无托盘环境自动跳过（测试覆盖）。

## 2. 实现期发现

1. `QAbstractNativeEventFilter` 不是 QObject —— 活动监视器需继承
   QObject 才能被 installEventFilter 接受。
2. search_service 需要引用枚举中文标签，为避免 services→ui 循环导入，
   标签数据下沉到 `app/models/labels.py`（UI 层再导出）。
3. 索引重建挂在 save() 末尾：所有变更路径（新增/编辑/删除/恢复/改名）
   统一经 save 收口，索引不会陈旧；保存失败时索引保持原状。
