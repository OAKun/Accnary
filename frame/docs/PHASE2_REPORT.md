## 1. 界面交付内容（app/ui/）

### 1.1 视觉体系（theme.py）

- 浅色主题优先 + **深色模式一键切换**（工具栏按钮，偏好持久化到 QSettings）
- 现代扁平风格：卡片式面板、8px 圆角、细边框、留白呼吸感；无 Qt 默认陈旧外观
- 主色取自应用图标（蓝色）；主/危险/幽灵三种按钮变体；自定义滚动条/菜单/提示
- Qt 6 默认启用高 DPI 缩放，无额外配置

### 1.2 解锁窗口（unlock_dialog.py）

- 最近使用的密码库列表（只记路径，凭证绝不落盘；测试可注入隔离）
- 主密码解锁，错误密码/损坏文件/缺失文件均有明确中文提示
- **新建密码库流程**：路径选择 + 两次确认 + 最小长度校验，创建后直接进入主界面
- 浏览文件对话框（打开 / 新建两种模式）

### 1.3 主窗口（main_window.py）

- **三栏布局**：左侧分类导航（全部账户 / 收藏 / 最近使用 + 按平台类型九类），
  中间账户列表（平台·别名·★收藏，副行用户名+网址），右侧详情面板
  （QSplitter 可拖动收起，适配小窗口）
- 顶部全局搜索框（Ctrl+F）：即时过滤平台/别名/用户名/邮箱/手机号/网址/
  备注/身份标签；分类与搜索叠加生效
- 工具栏：新建账户（Ctrl+N）/ 编辑（Ctrl+E，双击列表同效）/ 删除（确认框，
  进回收站可恢复）/ 锁定（Ctrl+L，锁后需重新解锁）/ 深浅色切换
- 状态栏：库名、账户/平台数、收藏数、最近使用数
- 保存失败分流：文件冲突 → 询问"重新加载"；其他错误 → 明确报错不静默

### 1.4 详情面板（detail_panel.py）

- 凭据卡：用户名/网址/邮箱/手机号一键复制；**密码默认掩码，显示/隐藏 + 复制**
- 登录方式列表（类型 + 关联身份中文标签 + 备注）
- 绑定身份（角色 + 身份名 + 身份类型）
- 付费授权卡（类型/激活码掩码/订单/有效期/渠道/设备数）
- 自定义字段（protected 字段同样掩码）；备注；创建/修改时间戳
- 空状态提示文案

### 1.5 新建/编辑对话框（account_editor.py）

- 渐进式表单：默认只显示 平台/类型/别名/用户名/密码/网址/主要登录方式/
  注册邮箱/手机号/备注；**"更多选项"折叠区**承载复杂结构
- 折叠区四组：其他登录方式（类型+身份+备注，可增删）、绑定身份（角色+身份
  选择，可增删 + 内联**新建身份**小对话框）、付费授权（类型/激活码/订单/
  日期/设备数）、自定义字段（键/值/隐藏，可增删）
- 密码框内联**安全随机生成**按钮（secrets，默认 20 位）
- 编辑模式：全部登录方式无损载入高级列表（身份引用/备注绝不因编辑丢失）；
  自定义字段的增删改在保存时与条目属性精确对账

### 1.6 复制与剪贴板（security/clipboard.py）

- 所有"复制"按钮走 `copy_with_auto_clear`：**30 秒后条件清空剪贴板**，
  用户已复制新内容则绝不清除（Win+V 历史等残余风险在代码与报告中明示）

### 1.7 启动链（main.py）

- `python main.py`：解锁窗口 → 主窗口；`--check` 栈自检；`--smoke`
  离屏组装全 UI + 临时库自动验证（供回归使用）
- 应用图标：`assets/app-icon.png`（蓝色钥匙孔字母 A）已接入窗口与 QApplication

## 2. 实现期发现（已修复）

1. **PySide6 6.12 的 `QWidget.addAction(QAction)` 重载不可用** —— 快捷键
   改用 `QShortcut` 实现（Ctrl+F/N/E/L 全部生效）。
2. **str 子类枚举经 QVariant 后变成裸字符串** —— 组合框统一存 `.value`，
   组装处用 `EnumCls(value)` 强转，否则序列化抛 `'str' has no 'value'`。
3. **编辑器自定义字段被 `_assemble` 提前覆盖导致漏写** —— 编辑模式下
   custom_fields 的唯一属主改为 `_sync_custom_fields`（与条目属性精确对账）。
4. `add_account` 传入新建 Service 对象时不会自动建组 —— 已补
   "首个账户落组"逻辑；`CatalogService.identity()` 委托方法补齐。

### GUI 测试发现并当场修复的问题

1. **QSettings 写入注册表**（真 bug）：PySide6 的 `QSettings(org, app)`
   构造函数不管 `setDefaultFormat` 一律用 NativeFormat —— "最近列表/主题"
   被写进 `HKCU\Software\Accnary`。已改为显式 `QSettings(IniFormat,
   UserScope, …)`（app/ui/settings.py），配置落 `%APPDATA%\Accnary\Accnary.ini`。
2. **Qt 标准按钮英文**（Yes/No）：启动时加载 PySide6 自带 `qt_zh_CN.qm`
   翻译，恢复为"是/否"。
3. **Qt 模态对话框 UIA 子树不完整**（已知 Qt 可访问性怪癖，自动化测试
   因此改用键盘+坐标驱动；对普通鼠标用户无影响）——记为无障碍改进项。
4. 测试脚本自身的教训：合成按键会被中文输入法拦截（改剪贴板粘贴）、
   pywinauto 窗口匹配必须按 PID 树限定（用户实例与测试实例同标题并存）。
