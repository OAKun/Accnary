# Accnary 使用说明（独立验收修改稿）

## 开始使用

打开程序，选择本地 KDBX 文件并输入主密码。新建库需要填写保存位置并确认两次主密码；主密码遗失无法重置或找回。建议先使用虚构账号熟悉操作，并在迁入重要凭据前阅读安全说明；本程序未经过独立第三方安全审计。

## 记录账号

“新建账户”默认填写平台名称、用户名、密码、网址、登录方式及备注。QQ、微信可直接作为平台名称，QQ 号、微信号填在用户名中。密码、网址可以为空。

编辑器分为“基本资料”“平台与联系”“登录与绑定”“许可证”“自定义”五个标签页，可维护别名、注册邮箱、手机号、其他登录方式、身份绑定、不同用途的邮箱、许可证及自定义字段。身份只登记一次，通过 UUID 被多个软件账号引用；普通账户记录与第三方登录身份不能未经确认自动合并。

只有点击“保存”才提交。取消不会把新建身份提前写入密码库；保存失败时表单保留，可修正或取消。删除进入回收站，恢复保留账户 UUID。

## 查找与复制

Ctrl+F 聚焦搜索。可输入账号名称、邮箱、手机号、网址的一部分，也可粘贴带很长路径和参数的网址；按域名和已保存的网址定位。Esc 清空搜索。

选择账户后，在右侧复制用户名、密码或其他值。编辑在详情右上角，删除在“更多账户操作”菜单中。左侧保留最近使用与平台分类；收藏入口已移除，旧库中的收藏标记继续保留兼容。密码及受保护字段默认打码，只有主动点击“显示”才展示。复制后约 30 秒条件清空；随后复制的新内容不会被本程序清除。Windows 剪贴板历史或其他剪贴板工具可能已经捕获内容，Accnary 不改变系统历史设置。

## 锁定和退出

- Ctrl+L、工具栏“锁定”或空闲超时会锁定当前库；主窗口直接显示密码输入区，重新输入主密码即可继续使用同一个库，不再弹出文件选择窗口。
- 空闲自动锁定默认 10 分钟，可在设置中调整；保留 Windows 锁屏和休眠消息联动。
- 最小化进入普通 Windows 任务栏。点击右上角关闭按钮正常退出，不隐藏到托盘，不注册全局呼出热键。
- 如模型仍有未保存改动，退出前尝试保存；保存失败时可以取消退出，或者明确放弃改动。
- 锁定会取消当前未保存的编辑表单，并清空账号列表、详情及搜索内容。

设置窗口可以切换深浅色和调整空闲锁定时间。三栏宽度可拖动调整，退出时保存非敏感布局偏好。

软件默认在启动后自动检查 ToolHub 上是否有新版（最多每 24 小时联网检查一次）；也可从主窗口“更多 → 检查更新”手动检查。发现新版本后会先询问，只有确认后才下载并校验 SHA-256，随后安全替换程序 EXE。更新不读取或上传密码库，密码库、加密备份及 `.lock` 协调文件均不会被更新流程替换。可在设置中关闭启动检查。

## 备份和恢复

左侧“备份与恢复”可导出已验证的加密 KDBX 副本，也可选择加密备份恢复。恢复前输入该备份的主密码，并确认目标文件；恢复前的库保留为 `.pre-restore.bak`。

每次保存还会保留 `<库名>.kdbx.bak` 快照。修改主密码不会重新加密已有备份，所以旧备份仍需旧密码。建议另外保存异地加密副本。

`.kdbx.lock` 文件只含零字节协调标记；程序退出会释放操作系统锁，标记文件可以保留。文件存在不表示程序在后台运行。请勿在多个实例运行期间手动删除它。

## 故障处理

外部工具改过库文件时，重新加载最新内容后再编辑。磁盘满、文件占用或权限问题会阻止保存，不应通过反复覆盖来处理。发生异常时先保留原文件、`.bak` 和其他副本；原子替换与 fsync 不能代替对真实断电、存储故障的完整验证。

Python 托管内存无法保证彻底擦除敏感字符串；本次工程验收不是第三方渗透测试或生产安全认证。
